## 🕹️ О проекте

**GTA Radar** — это кастомное навигационное приложение для Wear OS, вдохновленное культовым интерфейсом мини-карты из GTA: Vice City. Приложение превращает привычные поездки и прогулки в игровой процесс в стиле открытого мира с кастомными иконками миссий, точек интереса и ретро-вайбом 80-х.

---

## ✨ Основные возможности

* **Интерфейс в стиле Vice City:** Неоновые акценты, стилизованная круглая мини-карта и индикатор севера (`N`).
* **Интерактивные маркеры (Миссии и Места):** Убежища, бары, магазины одежды, стриптиз-клубы, банкоматы, казино и кастомные точки с фото из галереи.
* **Построение маршрутов:** Интеграция с OSRM для прорисовки золотой линии маршрута прямо на карте.
* **Вращение по компасу:** Поддержка датчиков ориентации устройства для автоматического поворота карты по направлению взгляда.
* **Кастомизация:** Добавление собственных объектов и точек по долгому нажатию на карту с выбором иконок и редактированием описаний.

---

## 🧰 Технологический стек

* **Платформа:** Wear OS (Min SDK 36, Target SDK 37)
* **UI:** Jetpack Compose for Wear OS, Material3
* **Картографический движок:** MapLibre Android SDK (`11.5.1`)
* **Геолокация:** Google Play Services Location
* **Язык:** Kotlin 2.2.10
